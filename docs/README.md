# MegaOrbitals documentation

MegaOrbitals is a Paper 26.1.2 plugin with 1322 orbital strike cannons.

## For server owners

- **[Getting started](getting-started.md)**: install the plugin, fire your first cannon, hand out cannon items.
- **[Commands and permissions](commands.md)**: every command and permission node.
- **[Configuration](configuration.md)**: `config.yml`, the per-cannon files and the language files.
- **[Features](features.md)**: undo, tiers and crafting, spotter binoculars, satellites, the arsenal, Discord alerts and more.
- **[FAQ and troubleshooting](faq.md)**: common questions and fixes.
- **[Cannon list](../CANNONS.md)**: all 1322 cannons with their ids, tiers and descriptions.

## For developers

- **[Making an addon](addons.md)**: add your own cannons from a separate plugin, and react to cannons being fired.
- **[API reference](api-reference.md)**: the classes and helper methods you can use.
- **[Example addon](../examples/example-addon)**: a complete addon you can copy.
- **[Contributing](../CONTRIBUTING.md)**: add cannons to MegaOrbitals itself.
- **[Changelog](../CHANGELOG.md)**: what changed in each version.
